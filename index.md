# Siraj Shorts Uploader

Siraj Shorts Uploader is a private, personal tool. It uploads short videos made by its owner to the owner's own YouTube channels (Curio Vault and The Notification Box) using the YouTube Data API. It is not offered to the public and has no other users.

## Privacy Policy

Last updated: 29 October 2026

**What the app accesses.** When the owner signs in with Google, the app asks for permission to upload videos to the owner's YouTube channel, to edit the titles, descriptions and tags of those videos, and to list the channel's videos. It does not access any other Google data.

**How the data is used.** The access is used only to upload the owner's own videos and set their details. Nothing is used for advertising, profiling or any other purpose.

**Storage and sharing.** Sign-in tokens are stored only on the owner's own computer. No data is sold, shared with third parties, or sent to any server other than Google's.

**YouTube API Services.** This app uses YouTube API Services. By using it you agree to the [YouTube Terms of Service](https://www.youtube.com/t/terms). See also the [Google Privacy Policy](https://policies.google.com/privacy).

**Revoking access.** Access can be removed at any time at [Google Account permissions](https://myaccount.google.com/permissions). Deleting the app's local token file removes all stored data.
